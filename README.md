## Acronis Cyber Protect 实际上是如何备份 VMware 虚拟机的

Acronis Cyber Protect 通过一个专用 agent 来备份 VMware 虚拟机，该 agent 与你的虚拟化层进行通信，而不是在每个虚拟机内部安装备份软件。此 agent 有两种部署方式，选择哪一种取决于你的基础设施：

1. **Agent for VMware (Windows)** — 安装在可以访问你的 vCenter Server 和虚拟机存储的 Windows 机器上。这是在已经有运行着 Windows 的管理服务器时的选择。
2. **Agent for VMware (Virtual Appliance)** — 直接部署在 ESXi 主机上。这是将 agent 作为轻量级虚拟设备运行，如果你不想占用一台 Windows 服务器仅用于备份，那么这个选项非常方便。

一旦连接上 agent，Acronis 就能执行整个虚拟机的镜像备份，并从虚拟机备份中进行文件级恢复，这意味着你可以恢复单个文件，而不必为了找回一个电子表格而恢复整个 500 GB 的虚拟机。对于跨 VMware 和 Hyper-V 混合运行的环境，Acronis 支持 Changed Block Tracking (CBT)，这能显著减少连续备份之间的数据传输量。

更高的功能层级增加了 VMware 管理员关心的一些内容：从备份点运行虚拟机（Run VM）、带故障转移和故障回退的虚拟机复制，以及感知应用程序的备份，这样即使不停止 SQL Server 或 Exchange，也能以一致的状态进行备份。

这里有一个值得提前说明的细节：Acronis 将其中一些功能限制在其 Standard 和 Advanced 许可层级中，而通过托管服务商使用 Acronis 时，你获得的功能取决于该服务商所配置的许可。Sharktech 的页面指出，应用程序和数据库保护“取决于工作负载支持和许可”，如果你需要这些具体功能，建议在付费前检查结账时显示的选项。

## 定价陷阱：为什么在这个服务上按月付费更好

这是这项服务最反直觉的一点：超额存储费用随着计费周期的延长而*增加*。月付方案每 GB 超额收费 0.02 美元。季付方案翻倍至 $0.04。年付方案达到 $0.12，是月付费率的六倍。

围绕这个问题规划一下：

- **固定的 200 GB 足够使用？** 那么年付方案胜出：$24/年折合每月 $2，而月付方案是每月 $4。如果从不产生超额费用，预付是最便宜的方式。
- **超出 200 GB 很多？** 计算一下。如果使用 400 GB，月付方案每月花费 $4 + (200 × $0.02) = $8。年付方案在纸面上是每月 $2，但超额费用在 $0.12/GB，这意味着 $2 + (200 × $0.12) = $26/月，考虑到超额计费是随每次使用发生的，这相当于每月 $26。这是三倍多的差距，而且超限越多，差距越大。
- **用量波动？** 月付方案也让你可以在不需要时缩减容量，而预付周期会锁定你的固定费用。

实际意义是：如果你知道你的虚拟机备份可以塞进 200 GB，年付方案是最经济的。如果你保护的是几个大型数据库虚拟机并且会超过这个容量，按月付费并按 $0.02/GB 的超额费率付费。 Sharktech 让你可以在订购前计算，因为最终价格会在客户门户的结账时确认——👉 [打开门户并检查你的容量和超额情况](https://bit.ly/SharKtech)。
